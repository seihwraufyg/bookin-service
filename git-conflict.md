# Описание конфликта в Git - Bookin Service

## Где возник конфликт
Конфликт возник при выполнении команды `git merge fix/conflict-demo` в ветке `master`.

## Почему возник конфликт
В двух ветках (`feature/flask-api` и `fix/conflict-demo`) были внесены изменения в одну и ту же секцию файла `README.md` с описанием возможностей сервиса.

В `feature/flask-api` было добавлено описание API-возможностей.
В `fix/conflict-demo` было добавлено описание функциональных возможностей.

## Как был разрешён конфликт
1. С помощью `git status` было определено, что конфликт в файле `README.md`
2. Файл был открыт в редакторе, где были видны маркеры конфликта
3. Было принято решение объединить обе версии, создав полный список возможностей
4. Оставлены все функции из обоих веток
5. После исправления выполнен `git add README.md`
6. Создан коммит `merge: resolve conflict in README.md`

## Результат
Конфликт успешно разрешён. В README теперь содержится полный список всех функций сервиса.
