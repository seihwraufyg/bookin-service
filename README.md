## Описание проекта
Сервис для бронирования отелей, номеров и управления бронированиями.

## Основные функции
- Поиск доступных отелей
- Просмотр номеров
- Бронирование номеров
- Отмена бронирования
- Просмотр истории бронирований

## Технологии
- Язык: Python (Flask)
- База данных: PostgreSQL
- Контейнеризация: Docker
- Кеширование: Redis

## API эндпоинты
- GET /hotels - список отелей
- GET /hotels/{id} - информация об отеле
- GET /rooms - доступные номера
- POST /bookings - создать бронирование
- GET /bookings - мои бронирования
- DELETE /bookings/{id} - отменить бронирование
